# VR 텔레포트 및 로코모션

## 개요

VR(XR) 모드에서 플레이어는 HMD 트래킹과 조이스틱 기반 이동·회전을 사용합니다. 텔레포트는 `Player.Mine.TeleportPlayer`로 수행하며, VR 환경에서는 멀미를 줄이기 위해 연속 이동보다 텔레포트를 우선 고려하는 것이 좋습니다.

## 언제 사용하나요?

- VR 전용 콘텐츠에서 플레이어 이동·텔레포트를 설계할 때
- VR 사용자 멀미를 최소화하고 싶을 때
- HMD 트래킹과 조이스틱 회전 동작을 이해하고 싶을 때

## 준비사항

- Viven SDK가 적용된 월드
- VR(XR) 플레이 모드 지원
- Lua 스크립트 또는 C# API 접근 권한

## VR 로코모션 동작

### HMD 트래킹

- VR 모드에서는 `TrackingSpace`가 HMD 위치·회전을 실시간 반영합니다.
- **이동 중이 아닐 때**: HMD 움직임에 따른 머리 이동이 플레이어 위치에 반영됩니다(자연스러운 보행).
- **이동 중일 때**: 조이스틱 입력만 사용하고, HMD 트래킹으로 인한 이동은 무시됩니다.

### 조이스틱 스냅 회전

- 조이스틱을 좌우로 기울이면 **15° 단위 스냅 회전**이 적용됩니다.
- 한 번 기울이면 한 번만 회전하고, 중립으로 돌리면 다음 입력을 받을 수 있습니다.
- 캐릭터의 Forward 방향을 기준으로 회전하며, HMD 트래킹 공간의 회전이 함께 적용됩니다.

### 텔레포트

VR에서도 `Player.Mine.TeleportPlayer(pos, rot)`를 사용합니다. 텔레포트 시:

1. 카메라와 머리 회전이 초기화됩니다.
2. `XrTrackingSpace.Initialize()`로 트래킹 공간이 리셋됩니다.
3. CharacterController가 지정 위치·회전으로 즉시 이동합니다.

자세한 텔레포트 사용법은 [아바타 이동 및 조작](01-avatar-movement-and-controls.md#텔레포트)을 참고하세요.

## VR 환경에서 멀미 유의사항

VR에서는 시선과 몸의 움직임 불일치가 멀미를 유발할 수 있습니다. 다음을 권장합니다.

| 항목 | 권장 | 비권장 |
|------|------|--------|
| **이동 방식** | 텔레포트 | 연속 스틱 이동(특히 빠른 속도) |
| **회전** | 스냅 회전(15° 등) | 부드러운 연속 회전 |
| **높이 변화** | 완만한 경사, 계단 | 급격한 상하 이동 |
| **시선·이동 방향** | 일치 | 불일치(옆으로 걸어가며 앞을 보는 등) |

- **텔레포트 우선**: 장거리 이동, 스폰 포인트 이동 등은 텔레포트로 처리하는 것이 안전합니다.
- **스냅 회전**: Viven은 기본적으로 15° 스냅 회전을 사용하므로, 추가 설정 없이도 비교적 안전합니다.
- **콘텐츠 설계**: 급격한 높이 변화, 좁은 회전 공간, 빠른 연속 이동은 피하는 것이 좋습니다.

## 진행 순서

1. [아바타 이동 및 조작](01-avatar-movement-and-controls.md)에서 시점·Forward·텔레포트 기본 사용법 확인
2. VR 전용 이동·텔레포트 로직을 Lua 또는 C#로 구현
3. `Player.Mine.TeleportPlayer`로 스폰 포인트, 워프 존 등에 텔레포트 적용

## 확인 방법

- VR 헤드셋으로 플레이하여 HMD 트래킹과 조이스틱 회전이 자연스럽게 동작하는지 확인
- 텔레포트 후 위치·회전이 정확한지 확인
- 장시간 플레이 시 멀미 유발 요소가 없는지 테스트

## 자주 일어나는 실수

- **연속 이동 과다 사용**: VR에서 장거리 연속 이동은 멀미를 유발할 수 있으므로, 텔레포트나 짧은 구간 이동으로 나누는 것이 좋습니다.
- **텔레포트 직후 상호작용**: `IsTeleporting`이 해제될 때까지 입력이 잠기므로, 직후 즉시 상호작용을 요구하지 마세요.
- **트래킹 공간 무시**: `SetTransform` 또는 `TeleportTo` 후 `XrTrackingSpace.Initialize()`가 호출되어야 HMD 오프셋이 올바르게 적용됩니다. Viven 내부에서 자동 처리되므로 별도 호출은 필요 없습니다.
