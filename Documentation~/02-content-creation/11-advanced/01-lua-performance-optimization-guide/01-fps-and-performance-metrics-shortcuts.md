# FPS 및 성능 지표 확인 (단축키)

## 개요

Viven 앱 실행 중에 실시간으로 프레임 레이트(FPS), 메모리 사용량, 하드웨어 정보 등을 확인할 수 있는 성능 오버레이 기능을 제공합니다.

## 언제 사용하나요?

- 콘텐츠 제작 중 프레임 드랍이 발생하는 지점을 찾을 때
- 메모리 누수(Memory Leak)가 의심될 때
- 현재 실행 중인 기기의 사양 정보를 확인하고 싶을 때

## 준비사항

- Viven SDK가 포함된 Unity 프로젝트 혹은 빌드된 Viven 앱

## 진행 순서

1. Viven 앱을 실행합니다.
2. 키보드의 **F9** 키를 누릅니다.
3. 화면 구석에 성능 지표가 표시되는지 확인합니다.
4. 다시 **F9** 키를 누르면 성능 지표가 사라집니다.

## 확인 방법

성능 오버레이가 활성화되면 다음과 같은 정보를 확인할 수 있습니다.

- **FPS**: 현재 프레임 레이트 및 평균(AVG)/최소(MIN) FPS
- **MEM TOTAL**: 전체 메모리 사용량
- **MEM ALLOC**: 할당된 메모리 사용량
