# 고급 (Advanced) 개요

## 개요

Viven 컨텐츠의 품질을 높이고 개발 효율을 극대화하기 위한 고급 기능들을 설명합니다. 성능 최적화, 디버깅 도구 활용, 그리고 Lua 개발 환경 설정을 통해 더 전문적인 컨텐츠를 제작할 수 있습니다.

## 주요 특징

- **Lua 성능 최적화**: FPS와 성능 지표를 확인하고, Lua 스크립트의 실행 효율을 높이는 가이드를 제공합니다.
- **EmmyLua 디버거 연결**: VSCode 등 외부 IDE와 연동하여 실시간 중단점(Breakpoint)과 변수 조사를 수행합니다.
- **Lua Language Server 설정**: 실시간 문법 검사, 타입 추론, 자동 완성을 통해 개발 속도와 코드 안정성을 높입니다.
- **Viven SDK 로그 분석**: 시스템 로그를 통해 런타임 오류를 정밀하게 진단하고 해결합니다.

## 학습 순서

1. **[Lua 성능 최적화 가이드](./01-lua-performance-optimization-guide/00-overview.md)**: 성능 지표 확인 방법과 최적화 기법을 배웁니다.
2. **[EmmyLua를 사용한 디버거 연결](./02-emmylua-debugger-connection/00-overview.md)**: 외부 IDE와 디버거를 연결하여 실시간 디버깅 환경을 구축합니다.
3. **[Lua Language Server 설정](./03-lua-language-server-setup/00-overview.md)**: LuaLS를 활용한 문법 검사와 타입 Annotation 활용법을 익힙니다.

## 준비사항

- Viven SDK가 설치된 Unity 프로젝트
- Lua 스크립트 작성을 위한 외부 IDE (VSCode 권장)
- 기본적인 성능 최적화 및 디버깅 개념에 대한 이해
