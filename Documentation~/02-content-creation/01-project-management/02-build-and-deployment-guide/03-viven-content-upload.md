# Viven Content Upload

## 개요

VMap, VObject, VAvatar를 Viven 홈페이지를 통해 업로드하는 방법을 설명합니다. 업로드된 콘텐츠는 심사 과정을 거친 뒤 Viven 플랫폼에서 사용 및 배포할 수 있습니다.

## 언제 사용하나요?

- Unity에서 빌드한 `.vmap`, `.vobj`, `.vavt` 파일을 Viven에 등록하려 할 때
- 맵, 오브젝트, 아바타를 플랫폼에 배포해 다른 사용자가 사용할 수 있게 하려 할 때

## 준비사항

- Viven 계정 및 로그인
- 사전에 빌드한 콘텐츠 파일
  - VMap: `.vmap` 파일
  - VObject: `.vobj` 파일
  - VAvatar: `.vavt` 파일
- 빌드 방법은 각각 [VMap 빌드 방법](01-vmap-build-process.md), [VObject 빌드 방법](02-vobject-build-process.md), [VAvatar 빌드 방법](../../08-characters/01-viven-avatar-system.md)을 참고하세요.

## 진행 순서

### 1. Viven 홈페이지 접속 및 로그인

Viven 홈페이지에 접속하여 로그인합니다.

### 2. 콘텐츠 심사관리로 이동

상단 메뉴에서 **콘텐츠 심사관리** 버튼을 클릭합니다.

### 3. 콘텐츠 심사요청

**콘텐츠 심사요청**을 클릭합니다.

### 4. 업로드할 콘텐츠 유형 선택

업로드할 콘텐츠에 맞는 버튼을 클릭합니다.

| 버튼 | 업로드 파일 | 설명 |
| --- | --- | --- |
| 맵 | `.vmap` | VMap(월드) 콘텐츠 |
| 오브젝트 | `.vobj` | VObject(상호작용 오브젝트) 콘텐츠 |
| 아바타 | `.vavt` | VAvatar(캐릭터) 콘텐츠 |

### 5. 기본 정보 입력 및 파일 등록

심사 진행을 위해 기본 정보를 입력하면 파일 등록 페이지가 나타납니다.

- **파일 등록** 영역에 사전에 빌드한 해당 확장자 파일을 업로드합니다.
- 필요한 경우 미리보기 이미지, 설명 등 추가 정보를 입력합니다.

### 6. 업로드 완료 확인

업로드가 성공하면 팝업 창이 표시됩니다. 이제 콘텐츠는 심사 과정을 거쳐 Viven에 배포됩니다.

## 콘텐츠 심사 과정

업로드된 콘텐츠는 다음 단계를 거쳐 배포됩니다.

### 심사 대기

- 심사 요청이 제출되면 콘텐츠는 **심사 대기** 상태로 전환됩니다.
- 심사팀이 콘텐츠를 검토할 때까지 기다리게 됩니다.
- 심사 상태는 Viven 홈페이지의 **콘텐츠 심사 관리** 페이지에서 확인할 수 있습니다.
- 승인 상태가 되면 콘텐츠를 **전시 상태**로 변경합니다.

### 진행중

- 심사팀이 콘텐츠를 검토 중인 상태입니다.
- 심사 중에는 다음 사항을 점검합니다:
  - 콘텐츠가 규정에 맞는지 확인
  - 파일의 정확성 및 품질 확인
  - 미리보기 이미지의 적합성 검토
  - 콘텐츠가 기술적 요구사항을 충족하는지 확인
- 문제가 있으면 심사 요청이 **반려**될 수 있습니다.

### 승인

- 콘텐츠가 모든 요구사항을 충족하면 **심사 승인** 상태로 전환됩니다.
- 승인된 콘텐츠는 Viven 플랫폼에서 사용 및 배포가 가능해집니다.
- 콘텐츠를 **전시 상태**로 변경하면 사용자가 해당 콘텐츠를 사용할 수 있습니다.

## 확인 방법

- 업로드 성공 시 팝업 창이 표시됩니다.
- **콘텐츠 심사 관리** 페이지에서 심사 상태(대기, 진행중, 승인, 반려)를 확인할 수 있습니다.
- 승인 후 전시 상태로 변경했는지 확인합니다.

## 자주 일어나는 실수

- **파일 형식 오류**: VMap은 `.vmap`, VObject는 `.vobj`, VAvatar는 `.vavt` 확장자 파일을 각각 해당 유형에 맞게 업로드해야 합니다.
- **미리보기 이미지 미준수**: 미리보기 이미지는 요구 사항(권장 해상도, 파일 크기)을 준수해야 합니다. 확인하지 않으면 반려될 수 있습니다.
- **빌드 미완료**: 빌드가 완료되지 않은 파일을 업로드하면 심사에서 반려될 수 있습니다. 빌드 성공 여부를 먼저 확인하세요.
