# 프로젝트 관리 (Project Management) 개요

## 개요

Viven 컨텐츠 제작의 시작부터 배포까지의 전체적인 흐름과 프로젝트 구조를 관리하는 방법을 설명합니다. 컨텐츠 유형을 올바르게 선택하고, 효율적으로 빌드 및 배포하며, 팀 단위로 협업하는 가이드를 제공합니다.

## 주요 특징

- **컨텐츠 유형 구분**: `VMap`, `VObject`, `VAvatar`의 역할을 명확히 구분하여 제작 범위를 설정합니다.
- **통합 빌드 시스템**: Windows, MacOS, Android, iOS 등 여러 플랫폼을 하나의 통합 빌드로 지원합니다.
- **DTS 서버 아키텍처**: Host/Client 모델을 기반으로 한 네트워크 동기화 원리를 이해합니다.
- **팀 협업 가이드**: Git과 Unity를 활용한 버전 관리 및 공동 작업 시의 주의 사항을 다룹니다.

## 학습 순서

1. **[Viven 컨텐츠 유형 이해하기](./01-viven-content-types-vobject-vmap-vavatar.md)**: `VMap`, `VObject`, `VAvatar` 중 내 작업에 맞는 유형을 선택합니다.
2. **[월드 생성 및 게시](./04-world-creation-and-publishing.md)**: 빈 Scene에서 시작하여 기본적인 월드를 구성하고 테스트 빌드하는 과정을 배웁니다.
3. **[컨텐츠 빌드 및 배포 가이드](./02-build-and-deployment-guide/00-overview.md)**: 실제 배포를 위한 플랫폼별 통합 빌드와 웹페이지 업로드 절차를 익힙니다.
4. **[Viven 아키텍처](./06-viven-architecture/00-overview.md)**: Host/Client 서버 모델과 네트워크 소유권 등 내부 동작 원리를 심도 있게 학습합니다.
5. **[팀 작업 및 버전 관리](./07-team-work/00-overview.md)**: 공동 작업을 위한 Git 설정과 Unity 프로젝트 관리 팁을 확인합니다.

## 준비사항

- Viven SDK가 설치된 Unity 프로젝트
- Viven 개발자 계정 (웹페이지 업로드용)
- Git 등 버전 관리 도구 (팀 작업 시)
