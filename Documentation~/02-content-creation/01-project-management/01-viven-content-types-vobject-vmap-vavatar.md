# Viven에서 제작할 수 있는 컨텐츠 이해하기

## 개요

이 문서는 `Viven`에서 제작할 수 있는 대표 컨텐츠 유형인 `VMap`, `VObject`, `VAvatar`를 간단히 소개합니다.

처음 제작을 시작할 때 어떤 형태의 컨텐츠를 만들어야 하는지 빠르게 판단할 수 있도록 돕는 허브 문서이며, 실제 업로드는 `Viven` 웹페이지에서 진행합니다. 업로드 절차 자체는 [Viven Content Upload](02-build-and-deployment-guide/03-viven-content-upload.md) 문서를 참고하세요.

## 언제 사용하나요?

- `Viven`에서 무엇을 만들 수 있는지 먼저 파악하고 싶을 때
- 내 작업이 `VMap`, `VObject`, `VAvatar` 중 어디에 해당하는지 구분하고 싶을 때
- 팀 내에서 제작 범위와 결과물을 같은 기준으로 정리하고 싶을 때
- 업로드 전에 컨텐츠 단위를 다시 확인하고 싶을 때

## 준비사항

- `Viven SDK`가 설치된 Unity 프로젝트
- 제작하려는 결과물이 `맵`, `오브젝트`, `아바타` 중 무엇인지에 대한 기본 구상
- 업로드에 사용할 `Viven` 계정

## 진행 순서

### 1. 만들고 싶은 결과물이 무엇인지 먼저 정리합니다

아래 질문으로 시작하면 컨텐츠 유형을 빠르게 나눌 수 있습니다.

- 플레이어가 들어가서 체험할 공간 전체를 만들고 싶은가?
- 월드 안에서 배치하고 상호작용할 개별 요소를 만들고 싶은가?
- 플레이어의 외형이나 캐릭터 표현 자체를 만들고 싶은가?

### 2. 컨텐츠 유형을 선택합니다

| 유형 | 이런 경우에 적합함 | 한 줄 설명 |
| --- | --- | --- |
| `VMap` | 하나의 공간, 씬, 월드 경험을 만들고 싶을 때 | 사용자가 들어가 활동할 맵 컨텐츠 |
| `VObject` | 월드 안에 배치할 개별 상호작용 요소를 만들고 싶을 때 | 잡기, 배치, 탑승, 착석 같은 상호작용을 담을 수 있는 오브젝트 컨텐츠 |
| `VAvatar` | 플레이어의 외형과 표현을 만들고 싶을 때 | 사용자 캐릭터에 적용되는 아바타 컨텐츠 |

### 3. 각 유형의 역할을 이해합니다

#### `VMap`

`VMap`은 사용자가 실제로 입장해 체험하는 공간 자체를 의미합니다.  
배경, 구조물, 동선, 조명, 분위기, 월드 규칙처럼 전체 경험을 구성하는 큰 단위의 컨텐츠를 만들 때 선택합니다.

예를 들어 전시 공간, 게임 맵, 교육용 시뮬레이션 공간, 이벤트 월드처럼 "하나의 체험 공간"을 배포하려는 경우 `VMap`으로 보는 편이 맞습니다.

#### `VObject`

`VObject`는 `VMap` 안에 배치되는 개별 오브젝트 컨텐츠입니다.  
사용자가 집을 수 있는 물건, 특정 위치에 둘 수 있는 소품, 탑승 가능한 장치, 앉을 수 있는 의자처럼 상호작용의 단위를 만들 때 사용합니다.

즉, `VMap`이 공간 전체라면 `VObject`는 그 공간 안에서 기능을 수행하는 구성 요소에 가깝습니다.

`VObject`는 독립적으로 빌드하여 사용할 수 있습니다. `VMap`에 포함되어 빌드된 경우 해당 맵에서만 사용되고, 별도로 빌드하여 업로드하면 여러 맵에서 꺼내서 사용할 수 있습니다.

#### `VAvatar`

`VAvatar`는 플레이어의 외형과 표현을 담당하는 아바타 컨텐츠입니다.  
캐릭터의 모습 자체를 제작하거나, 아바타 커스터마이징과 연결되는 결과물을 준비할 때 이 유형을 기준으로 이해하면 됩니다.

월드에 배치되는 배경 오브젝트나 소품이 아니라, 플레이어를 대표하는 캐릭터 자산이라는 점이 `VMap`, `VObject`와 가장 큰 차이입니다.

### 4. 업로드 경로를 확인합니다

컨텐츠 제작이 끝나면 업로드는 Unity Editor 내부가 아니라 `Viven` 웹페이지에서 진행합니다.

이 문서는 유형 안내만 다루며, 실제 업로드 순서와 화면은 [Viven Content Upload](02-build-and-deployment-guide/03-viven-content-upload.md) 문서에서 확인하세요.

## 확인 방법

아래 질문에 스스로 답할 수 있으면 컨텐츠 유형을 올바르게 구분한 것입니다.

- 이것이 하나의 체험 공간이면 `VMap`인가?
- 이것이 월드 안에 배치되는 개별 기능 오브젝트이면 `VObject`인가?
- 이것이 플레이어 외형이나 캐릭터 표현 자산이면 `VAvatar`인가?
- 업로드는 `Viven` 웹페이지에서 진행한다는 점을 알고 있는가?

## 자주 일어나는 실수

### `VMap`과 `VObject`를 같은 의미로 생각함

공간 전체를 만드는 작업과, 그 안에 들어가는 개별 오브젝트를 만드는 작업은 서로 다릅니다.  
월드 전체 경험을 배포하려는지, 월드 안에 넣을 요소 하나를 배포하려는지 먼저 구분하세요.

### `VAvatar`를 월드 배치용 에셋처럼 다룸

`VAvatar`는 플레이어 캐릭터를 위한 컨텐츠입니다.  
배경 장식물이나 인터랙션 오브젝트는 보통 `VObject` 또는 `VMap` 관점에서 정리하는 편이 맞습니다.

### 업로드를 Unity 내부 기능으로 오해함

컨텐츠 제작은 Unity에서 진행하지만, 업로드 경로는 `Viven` 웹페이지 기준입니다.  
배포 절차가 필요하면 반드시 업로드 가이드를 함께 확인하세요.
