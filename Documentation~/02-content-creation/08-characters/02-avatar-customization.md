# 아바타 제작 및 커스터마이징

## 개요

이 가이드는 VRM 모델을 Unity로 가져와 Viven 아바타 시스템(VAvatar)에 맞게 설정하는 방법을 설명합니다. VRM 모델은 Humanoid 리깅과 표정 설정을 포함하고 있어 Viven 아바타로 변환하기에 매우 적합합니다.

## 언제 사용하나요?

- VRoid Studio 등에서 제작한 VRM 모델을 Viven의 아바타로 사용하고 싶을 때 사용합니다.
- 아바타의 1인칭 시점 컬링(Culling)과 이름표 위치 등을 세밀하게 조정하고 싶을 때 사용합니다.

## 준비사항

- **Unity 6 프로젝트**: Viven SDK가 설치된 Unity 프로젝트가 필요합니다.
- **VRM 모델 파일**: `.vrm` 확장자의 아바타 모델 파일이 필요합니다.
- **UniVRM 패키지**: VRM 파일을 Unity에서 읽고 변환하기 위해 필요합니다.

## 진행 순서

### 1. VRM 모델 임포트
1. VRM 파일을 Unity 프로젝트의 `Assets` 폴더 내로 드래그하여 임포트합니다.
2. UniVRM에 의해 자동으로 생성된 프리팹을 씬(Scene)에 배치합니다.

### 2. Humanoid 리깅 확인
1. 임포트된 모델의 `FBX` 또는 생성된 프리팹의 `Rig` 탭에서 `Animation Type`이 `Humanoid`로 설정되어 있는지 확인합니다.
2. `Configure...` 버튼을 눌러 모든 본(Bone)이 올바르게 매핑되었는지 확인합니다. 특히 **Head** 본이 정확히 매핑되어야 아바타의 키가 올바르게 측정됩니다.

### 3. SDKVivenAvatar 컴포넌트 설정
아바타의 루트 오브젝트에 `SDKVivenAvatar` 컴포넌트를 추가하고 다음 항목을 설정합니다.

| 설정 항목 | 설명 |
| :--- | :--- |
| **Sdk Face** | 아바타의 얼굴 메쉬(SkinnedMeshRenderer)를 연결합니다. 1인칭 시점에서 이 메쉬는 자동으로 숨겨집니다. |
| **Sdk Character Culling Objects** | 얼굴 외에 1인칭 시점에서 숨겨야 할 추가 오브젝트(머리카락, 모자, 안경 등)를 리스트에 추가합니다. |
| **Sdk Nameplate Offset** | 아바타 머리 위에 표시될 이름표의 높이를 조정합니다. 기본값은 `0.3`입니다. |

### 4. VAvatar 프리팹 생성
1. 설정을 마친 아바타 오브젝트를 프로젝트 창으로 드래그하여 프리팹(Prefab)으로 만듭니다.
2. 이 프리팹이 Viven 플랫폼에 업로드할 최종 아바타 에셋이 됩니다.

## 확인 방법

- **자동 IK 동작**: 런타임에서 아바타가 생성되면 `VRIK` 컴포넌트가 자동으로 추가되고 본(Bone)을 감지하는지 확인합니다.
- **1인칭 컬링**: 1인칭 시점(POV)으로 전환했을 때 `Sdk Face`와 `Culling Objects`에 등록된 메쉬들이 화면에서 사라지는지 확인합니다.
- **이름표 위치**: 다른 플레이어의 시점에서 이름표가 머리 위에 적절한 높이로 떠 있는지 확인합니다.

## 자주 일어나는 실수

- **Head 본 누락**: Humanoid 설정에서 Head 본이 매핑되지 않으면 아바타의 키(`characterHeight`)가 `0`으로 계산되어 바닥에 묻히거나 비정상적으로 보일 수 있습니다.
- **컬링 오브젝트 미설정**: 1인칭 시점에서 자신의 머리카락이나 모자가 시야를 가리는 경우, 해당 오브젝트를 `Sdk Character Culling Objects`에 등록했는지 확인하십시오.
- **레이어 수동 변경**: Viven 시스템은 런타임에 `NotRender`와 `Player` 레이어를 자동으로 전환합니다. 제작 단계에서 레이어를 수동으로 고정하면 시점 전환 기능이 오작동할 수 있습니다.
