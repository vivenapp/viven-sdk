# 감정 표현 (Emote)

## 개요

Viven 아바타 시스템(VAvatar)은 사용자 정의 애니메이션을 감정 표현(Emote)으로 등록하여 사용할 수 있는 기능을 제공합니다. 이를 통해 아바타에 개성 있는 동작을 추가하고 Viven 내 UI를 통해 간편하게 실행할 수 있습니다.

## 언제 사용하나요?

- 아바타에 인사, 춤, 박수 등 특정한 동작을 추가하고 싶을 때 사용합니다.
- Viven 내 아바타 메뉴 UI에서 선택하여 실행할 수 있는 애니메이션 리스트를 구성할 때 사용합니다.

## 준비사항

- **애니메이션 클립**: 아바타의 Humanoid 리그와 호환되는 `.anim` 파일이 필요합니다.
- **아이콘 스프라이트**: UI에 표시될 감정 표현 아이콘(Sprite)이 필요합니다.
- **SDKCustomEmoteComponent**: 아바타 프리팹에 부착하여 감정 표현을 관리하는 컴포넌트입니다.

## 진행 순서

### 1. 컴포넌트 추가
1. 아바타 프리팹의 루트 오브젝트 또는 자식 오브젝트에 `SDKCustomEmoteComponent`를 추가합니다.

### 2. 감정 표현 리스트 설정
1. `Sdk Custom Emotes` 리스트의 `+` 버튼을 눌러 새로운 항목을 추가합니다.
2. 각 항목에 대해 다음 정보를 입력합니다.

| 설정 항목 | 설명 |
| :--- | :--- |
| **Emote Name** | Viven 내 UI에 표시될 감정 표현의 이름입니다. |
| **Emote Sprite** | UI에 표시될 아이콘 이미지(Sprite)입니다. |
| **Emote Clip** | 재생할 애니메이션 클립(.anim)을 연결합니다. |

### 3. 프리팹 저장 및 빌드
1. 설정을 마친 후 프리팹을 저장합니다.
2. 아바타를 빌드하여 Viven 플랫폼에 등록합니다.

## 확인 방법

- **Viven 내 UI 확인**: Viven에 접속하여 아바타 메뉴를 열었을 때, 설정한 `Emote Name`과 `Emote Sprite`가 리스트에 올바르게 표시되는지 확인합니다.
- **동작 실행**: 리스트에서 감정 표현을 선택했을 때 아바타가 해당 애니메이션을 정상적으로 재생하는지 확인합니다.

## 자주 일어나는 실수

- **애니메이션 호환성**: Humanoid 리그가 아닌 애니메이션 클립을 사용하면 아바타가 비정상적으로 움직이거나 동작하지 않을 수 있습니다. 반드시 Humanoid용 애니메이션을 사용하십시오.
- **아이콘 누락**: `Emote Sprite`를 설정하지 않으면 UI에서 아이콘이 보이지 않아 사용자가 구분하기 어려울 수 있습니다.
- **컴포넌트 위치**: `SDKCustomEmoteComponent`가 아바타 프리팹 내에 포함되어 있지 않으면 런타임에 감정 표현 리스트를 불러올 수 없습니다.
