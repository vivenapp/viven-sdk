# Viven 아바타 시스템 (VAvatar)

## 개요

Viven 아바타 시스템(VAvatar)은 사용자가 가상 세계에서 자신을 표현하는 중심적인 역할을 합니다. 이 시스템은 Unity의 Humanoid 애니메이션 시스템과 FinalIK를 기반으로 하며, 1인칭 및 3인칭 시점 모두에서 최적의 시각적 경험과 자연스러운 움직임을 제공합니다.

## 언제 사용하나요?

- 사용자가 직접 조작하거나 다른 플레이어에게 보여지는 캐릭터를 제작할 때 사용합니다.
- 아바타의 외형(의상, 얼굴 표현 등)을 커스터마이징하고 싶을 때 사용합니다.
- VR 환경에서 사용자의 실제 움직임을 아바타에 실시간으로 반영하고 싶을 때 사용합니다.

## 제공하는 주요 기능

- **자동 IK 설정**: FinalIK의 VRIK를 사용하여 VR 컨트롤러와 트래커의 움직임을 아바타에 자연스럽게 동기화합니다.
- **1인칭 시점 최적화**: 1인칭 시점에서 자신의 얼굴이나 머리 메쉬가 시야를 가리지 않도록 자동으로 숨김 처리(Culling)합니다.
- **커스터마이징 시스템**: 의상(Outfit), 얼굴 표현(Facial Expression), 커스텀 애니메이션(Emote) 등을 쉽게 교체하고 제어할 수 있는 컴포넌트 구조를 제공합니다.
- **자동 키 측정**: 아바타의 Head 본과 Root 사이의 거리를 계산하여 캐릭터의 실제 키를 시스템에 반영합니다.

## 준비사항

- **Unity Humanoid 리깅**: 아바타 모델은 반드시 Unity의 Humanoid 리그 설정을 완료해야 합니다.
- **SDKVivenAvatar 컴포넌트**: 아바타 루트 오브젝트에 부착하여 기본 설정을 관리합니다.
- **필수 메쉬 구조**: 얼굴(Face)과 몸(Body) 메쉬가 분리되어 있으면 시점 제어가 더 용이합니다.

## 제작 방법

1. **아바타 모델 임포트**: 제작한 아바타 모델을 Unity 프로젝트로 가져온 뒤, `Animation Type`을 `Humanoid`로 설정합니다.
2. **SDKVivenAvatar 추가**: 아바타 프리팹의 최상단 오브젝트에 `SDKVivenAvatar` 컴포넌트를 추가합니다.
3. **메쉬 연결**:
   - `Sdk Face`: 아바타의 얼굴 메쉬(SkinnedMeshRenderer)를 연결합니다.
   - `Sdk Character Culling Objects`: 1인칭 시점에서 숨겨야 할 추가 오브젝트(머리카락, 모자 등)를 리스트에 등록합니다.
4. **추가 컴포넌트 설정 (선택 사항)**:
   - 의상 교체가 필요하다면 `SDKOutfitComponent`를 추가합니다.
   - 표정 변화가 필요하다면 `SDKFacialExpressionComponent`를 추가합니다.
   - 커스텀 감정 표현이 필요하다면 `SDKCustomEmoteComponent`를 추가합니다.
5. **프리팹 저장**: 설정을 마친 아바타를 프리팹으로 저장하여 Viven 콘텐츠로 빌드합니다.

## 제약 조건 및 주의사항

- **본 구조**: 반드시 Humanoid 표준 본 구조를 따라야 하며, Head 본이 누락되면 키 측정이 불가능합니다.
- **레이어 관리**: 1인칭 시점 처리를 위해 `NotRender`와 `Player` 레이어를 사용하므로, 아바타 오브젝트의 레이어를 임의로 변경하지 마십시오.
- **IK 충돌**: 애니메이터에서 직접 본을 제어하는 로직이 VRIK와 충돌할 수 있으므로, IK 가중치(Weight) 조절을 통해 제어해야 합니다.

## 빌드 및 업로드 방법

제작이 완료된 아바타는 Viven 전용 파일 형식(`.vavt`)으로 빌드하여 플랫폼에 등록해야 합니다.

1. **빌드 실행**: 프로젝트 창에서 설정이 완료된 아바타 프리팹을 마우스 오른쪽 버튼으로 클릭한 후, **Viven** > **Build Viven Avatar**를 선택합니다.
2. **파일 생성 확인**: 빌드가 완료되면 프로젝트 폴더 내에 `.vavt` 확장자를 가진 아바타 에셋 파일이 생성됩니다.
3. **플랫폼 등록**: 생성된 `.vavt` 파일을 Viven 공식 홈페이지 또는 관리자 도구를 통해 업로드하여 자신의 아바타 리스트에 등록합니다.

> **참고**: 만약 **Build Viven Avatar** 메뉴가 활성화되지 않는다면, 아바타 프리팹에 Missing된 스크립트가 있거나 프로젝트에 컴파일 에러가 없는지 확인하십시오.

## 확인 방법

- **1인칭 시점 확인**: 런타임에서 시점을 1인칭으로 변경했을 때, 자신의 얼굴 메쉬가 보이지 않고 시야가 확보되는지 확인합니다.
- **IK 동작 확인**: VR 모드에서 컨트롤러를 움직였을 때 아바타의 팔과 몸이 자연스럽게 따라오는지 확인합니다.
