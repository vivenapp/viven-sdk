# 커스텀 애니메이션 시스템 (Animator)

## 개요

Viven 아바타 시스템(VAvatar)은 아바타의 기본 동작(대기, 이동, 점프 등)을 사용자가 원하는 애니메이션으로 교체할 수 있는 애니메이션 오버라이드(Animation Override) 기능을 제공합니다. 이를 통해 아바타의 개성을 살린 독특한 움직임을 구현할 수 있습니다.

## 언제 사용하나요?

- 아바타의 기본 걷기, 달리기, 대기(Idle) 동작을 커스텀 애니메이션으로 바꾸고 싶을 때 사용합니다.
- 부상당한 캐릭터나 춤추는 듯한 이동 등 특수한 상황의 애니메이션을 적용하고 싶을 때 사용합니다.
- VR 컨트롤러의 기본 손 모양(Grab, Point 등)을 변경하고 싶을 때 사용합니다.

## 준비사항

- **애니메이션 클립**: 아바타의 Humanoid 리그와 호환되는 `.anim` 파일들이 필요합니다.
- **SDKOverrideAnimation (ScriptableObject)**: 오버라이드할 애니메이션 클립 목록을 담는 데이터 에셋입니다.
- **SDKOverrideAnimationComponent**: 아바타 프리팹에 부착하여 오버라이드 데이터 에셋을 연결하는 컴포넌트입니다.

## 진행 순서

### 1. 오버라이드 데이터 에셋 생성

1. 프로젝트 창에서 마우스 오른쪽 클릭 → **Create** → **Viven** → **Create Override Animation**을 선택합니다.
2. 생성된 `Override Animation` 에셋의 이름을 용도에 맞게 변경합니다.

### 2. 애니메이션 클립 연결

1. 생성한 `Override Animation` 에셋을 선택합니다.
2. 인스펙터 창에서 오버라이드하고 싶은 항목에 준비한 애니메이션 클립을 연결합니다.
   - **기본**: `Idle`, `Sitting_Idle`, `Jump`, `Turn_Left/Right` 등
   - **이동(걷기/달리기)**: 방향별 `Walk`, `Run`, `Walk_Start`, `Jump` 등
   - **손 동작**: 좌우 `Grab`, `Point`, `Rock`, `Thumb_Down` 등

### 3. 컴포넌트 추가 및 연결

1. 아바타 프리팹의 루트 오브젝트에 `SDKOverrideAnimationComponent`를 추가합니다.
2. `Sdk Override Animation` 필드에 방금 설정한 `Override Animation` 에셋을 연결합니다.

### 4. 프리팹 저장 및 빌드

1. 설정을 마친 후 프리팹을 저장합니다.
2. 아바타를 빌드하여 Viven 플랫폼에 등록합니다.

## 확인 방법

- **동작 확인**: Viven에 접속하여 아바타가 대기 중이거나 이동할 때, 설정한 커스텀 애니메이션이 정상적으로 재생되는지 확인합니다.
- **손 모양 확인**: VR 모드에서 컨트롤러 버튼을 조작할 때 설정한 손 모양 애니메이션이 적용되는지 확인합니다.

## 자주 일어나는 실수

- **Humanoid 호환성**: 오버라이드에 사용되는 애니메이션 클립은 반드시 아바타의 Humanoid 리그와 호환되어야 합니다.
- **일부 클립 누락**: 이동 방향별 애니메이션(예: `Walk_Forward_Left`) 중 일부를 누락하면 해당 방향으로 이동할 때 기본 애니메이션이 나오거나 부자연스럽게 보일 수 있습니다.
- **메모리 관리**: 너무 많은 고해상도 애니메이션 클립을 오버라이드하면 아바타 로딩 속도나 메모리 사용량에 영향을 줄 수 있습니다.
