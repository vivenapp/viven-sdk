# 페르소나 및 시나리오

> 관련 문서: [Skill 분류](02-skill-taxonomy.md) | [산출물 정리](07-output-summary.md)

본 문서는 Viven AI Agent Skill 설계의 기반이 되는 **페르소나 정의**, **시나리오**, **예상 프롬프트**를 정리합니다. Agent가 사용자 의도를 파악하고 적절한 Skill을 선택하는 데 참고합니다.

---

## 1단계: 페르소나 정의

Viven 콘텐츠 제작을 지원하는 AI Agent의 주요 사용자를 **3가지 페르소나**로 구분합니다.

### 페르소나 1: 비개발자 학생 (초급)

| 항목 | 내용 |
|------|------|
| **연령** | 20대 초반 |
| **경험** | Unity, Viven, Lua 모두 처음 |
| **목표** | 간단한 컨텐츠를 빠르게 만들어보고 싶음 |
| **특징** | 기술 용어에 익숙하지 않음, 추상적·일상어 표현 선호, 단계별 안내 필요 |

**AI Agent 활용 패턴**: 단계별로 나눠 요청 → Agent가 Lua 코드 + Hierarchy 구조 제안 → 사용자가 복사·붙여넣기

---

### 페르소나 2: 개발자 학생 (중급)

| 항목 | 내용 |
|------|------|
| **연령** | 20대 초반 |
| **경험** | Unity, C# 경험 있음 / Viven, Lua 처음 |
| **목표** | 다양한 컨텐츠를 시도하고 싶음 |
| **특징** | 기술 용어 이해 가능, 일반적인 기능 요청 가능, Viven/Lua 특화 지식 부족 |

**AI Agent 활용 패턴**: 기능 단위로 요청 → Agent가 Viven API + Lua 패턴 제안 → 사용자가 수정·확장

---

### 페르소나 3: 컨텐츠 제작자 (고급)

| 항목 | 내용 |
|------|------|
| **연령** | 20대 중반 |
| **경험** | Unity, Viven, C#, Lua 모두 경험 있음 |
| **목표** | 복잡한 멀티플레이·동기화·고급 상호작용 구현 |
| **특징** | Viven 키워드(GrabbableModule, RPC, CustomSyncView 등) 사용 가능, 아키텍처·최적화 관심 |

**AI Agent 활용 패턴**: 키워드 기반 정밀 요청 → Agent가 최적 패턴·문서 참조 제시 → 사용자가 통합·최적화

---

## 2단계: 시나리오

각 페르소나가 겪는 대표적인 사용 상황을 시나리오로 정리합니다.

### 페르소나 1: 비개발자 학생

| ID | 시나리오 | 상황 |
|----|----------|------|
| **S1-1** | 첫 컨텐츠 시작 | Viven에서 처음으로 UI를 만들어보려는 상황 |
| **S1-2** | 물체 상호작용 | 오브젝트를 잡았을 때 시각적 피드백을 주고 싶은 상황 |
| **S1-3** | 게임 루프 | 가위바위보처럼 선택 후 결과가 나오는 흐름을 만들고 싶은 상황 |
| **S1-4** | 에러 대응 | 스크립트 실행 시 nil 에러가 발생하여 원인을 모르는 상황 |
| **S1-5** | 추상적 요청 | 주사위 게임을 만들고 싶다는 막연한 의도만 있는 상황 |
| **S1-6** | 준비·시작 | Viven에서 새 컨텐츠를 만들기 위해 먼저 무엇을 해야 하는지 모르는 상황 |
| **S1-7** | 다음 단계 진행 | 버튼 뼈대를 만들었고, 다음에 무엇을 해야 할지 묻는 상황 |
| **S1-8** | 오디오 피드백 | 버튼을 누르면 소리가 나오게 하고 싶은 상황 |
| **S1-9** | 앉기 상호작용 | 의자에 앉으면 화면이나 상태가 바뀌게 하고 싶은 상황 |
| **S1-10** | 추상적 요청 | 순간이동(텔레포트) 기능을 만들고 싶다는 막연한 의도만 있는 상황 |
| **S1-11** | 타이머·대기 | 일정 시간 뒤에 무언가 나타나거나 실행되게 하고 싶은 상황 |
| **S1-12** | 추상적 요청 | 캐릭터 표정이나 감정을 바꾸는 기능을 만들고 싶은 상황 |
| **S1-13** | 채팅 표시 | 채팅 입력 시 화면에 메시지가 표시되게 하고 싶은 상황 |
| **S1-14** | 에러 대응 | "attempt to call nil" 에러가 발생하여 원인을 모르는 상황 |
| **S1-15** | 추상적 요청 | 미니게임을 만들고 싶다는 막연한 의도만 있는 상황 |

---

### 페르소나 2: 개발자 학생

| ID | 시나리오 | 상황 |
|----|----------|------|
| **S2-1** | 총기 구현 | 총을 잡아서 버튼 누르면 총알이 발사되게 만들고 싶은 상황 |
| **S2-2** | UI 상태 표시 | 플레이어별 점수 현황판을 UI에 표시하고 갱신하고 싶은 상황 |
| **S2-3** | 멀티플레이 | 주사위를 던졌을 때 결과가 모든 플레이어에게 보이게 하고 싶은 상황 |
| **S2-4** | Viven 특화 학습 | GrabbableModule의 onGrab에서 이펙트 재생하는 예제를 보고 싶은 상황 |
| **S2-5** | 에러 대응 | RPC 호출 시 함수를 찾을 수 없다는 에러가 발생한 상황 |
| **S2-6** | 프로젝트 설정 | Viven 맵 빌드 시 Addressable·OpenXR 설정을 확인하고 싶은 상황 |
| **S2-7** | SittableModule | SittableModule로 의자 앉기 기능을 구현하는 예제를 보고 싶은 상황 |
| **S2-8** | 방 상태 표시 | 방에 들어온 사람 수를 UI에 표시하고 싶은 상황 |
| **S2-9** | 비동기 처리 | 에셋 로드가 끝난 후에 UI를 띄우는 방식을 Lua로 구현하고 싶은 상황 |
| **S2-10** | 빌드·배포 | VObject 빌드 시 발생하는 에러를 해결하고 싶은 상황 |
| **S2-11** | 입력 처리 | PC·VR 버튼 입력을 Lua에서 받아 처리하고 싶은 상황 |
| **S2-12** | 채팅 API | 채팅 메시지를 보내고 받는 API 사용법을 알고 싶은 상황 |
| **S2-13** | 아바타 애니메이션 | 아바타 애니메이션을 오버라이드하는 방법을 적용하고 싶은 상황 |
| **S2-14** | Lua·RPC 직렬화 | Lua 테이블을 RPC로 보낼 때 직렬화 관련 주의사항을 확인하고 싶은 상황 |
| **S2-15** | 플레이어 API | 플레이어 텔레포트 API 사용법을 알고 싶은 상황 |

### 페르소나 3: 컨텐츠 제작자

| ID | 시나리오 | 상황 |
|----|----------|------|
| **S3-1** | 구체적 키워드 | GrabbableModule의 onGrab 시점에 이펙트를 재생하도록 구현하려는 상황 |
| **S3-2** | 네트워크 동기화 | RPC로 주사위 결과를 전달해 UI를 모두에게 갱신하려는 상황 |
| **S3-3** | CustomSyncView | CustomSyncView로 주사위 눈 값을 동기화하는 구조로 전환하려는 상황 |
| **S3-4** | 아키텍처 설계 | 4인 협동 미니게임의 Host 검증, RPC 흐름을 포함한 아키텍처를 설계하려는 상황 |
| **S3-5** | 트러블슈팅 | SyncView.IsMine이 false인데 receiveSyncUpdate가 호출되지 않는 원인을 파악하려는 상황 |
| **S3-6** | RoomProperty | RoomProperty로 게임 상태(라운드, 턴)를 관리하는 패턴을 적용하려는 상황 |
| **S3-7** | 동기화 방식 선택 | NetworkVariable과 CustomSyncView 중 주사위 눈 값 동기화에 적합한 방식을 선택하려는 상황 |
| **S3-8** | Host 검증 | RPC에서 Host만 실행하도록 검증하는 방법을 구현하려는 상황 |
| **S3-9** | 성능 최적화 | Lua에서 매 프레임 alloc을 줄이는 방법을 적용하려는 상황 |
| **S3-10** | VMap 설정 | ModuleScript에서 startPoint 초기화 시 주의할 점을 확인하려는 상황 |
| **S3-11** | RPC 방식 선택 | SendTargetRPC와 SendRPC 중 상황에 맞는 방식을 선택하려는 상황 |
| **S3-12** | NetworkVariable | NetworkVariable으로 플레이어 점수를 동기화하는 구조를 적용하려는 상황 |
| **S3-13** | Injection 트러블슈팅 | checkInject에서 local 사용 시 nil이 되는 원인을 파악하려는 상황 |
| **S3-14** | VAvatar 설정 | VAvatar Override Animation 설정 방법을 확인하려는 상황 |
